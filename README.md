# Calculadora Didática de Conversão de Números

Este programa oferece uma série de opções para converter números em diferentes sistemas e formatos, permitindo explorar as representações numéricas de maneira prática. As opções disponíveis são:

Converter para Binário: Converte um número para a sua representação binária.
Converter para Octal: Realiza a conversão de um número para o sistema octal.
Converter para Hexadecimal: Converte o número para a representação hexadecimal.
Converter para BCD (Código Decimal Codificado em Binário): Converte um número para a representação em BCD.
Converter para Complemento de 2 com 16 bits: Realiza a conversão de um número para a representação de complemento a 2 com 16 bits.
Converter para Float ou Double: Converte o número para os formatos de ponto flutuante, seja float ou double.
Escolha uma das opções para ver como o número inserido é convertido e entenda melhor os diferentes sistemas de numeração e formatos utilizados na computação.
